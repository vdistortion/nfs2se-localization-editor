# Результаты исследования NFS II SE

## Текстовые файлы

Для шести файлов `text.*` из проверенной сборки NFSIISE установлено:

- таблица состоит из 1502 записей по 12 байт, занимает 18024 байта;
- последние четыре байта каждой записи — абсолютное смещение строки в формате little-endian;
- строка заканчивается байтом `00`; первые восемь байт записи содержат дополнительные данные, точное назначение которых пока не подтверждено;
- при изменении длины строк необходимо обновлять смещения. Нельзя считать эти параметры универсальными для всех версий игры.

## Шрифты и русский эксперимент

В `fedata/pc/text/` найдены семь файлов `.ffn` с сигнатурой `FNTF`. В эксперименте были изменены копии пяти шрифтов: `fixed14`, `swiss13`, `swiss16`, `swiss18`, `swiss36a`. Из них извлечены 4-битные изображения атласов; расширенные атласы с кириллицей отображались в NFSIISE на Linux. Формат и поля метрик изучены не полностью.

Русский текст записывался в Windows-1251, кроме строчной `я`: вместо `FF` использован `98` в сочетании с модифицированными шрифтами. Это ограничивает совместимость с другими языками и оригинальными шрифтами. Внешние экспериментальные скрипты генерации шрифтов были утрачены при очистке временного каталога; готового воспроизводимого сборщика пока нет.

В проверенных экранах основная часть перевода работает. Кнопка `RACE` оставлена на английском: в соответствующем шрифте кириллица не подготовлена. Меню паузы остаётся на английском; источник его надписей не установлен. Начертание `ё` требует доработки. Сетевые и редкие экраны проверены не полностью.

Имена машин и трасс, музыка и большая часть титров намеренно оставлены на языке оригинала. Встроенные в изображения надписи могут требовать отдельных инструментов.

## NFSIISE

Проверенный вариант NFSIISE использует `text.*` из корня каталога игры, а шрифты — из `fedata/pc/text/`. Русский как отдельный язык в документации проекта не указан; эксперимент заменяет английский текст. Поддержка оригинальной Windows-версии игры и других игр NFS не подтверждена.
