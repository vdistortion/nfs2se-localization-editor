# NFS II SE Localization Editor

Проект кроссплатформенного редактора локализации Need for Speed II Special Edition. Первый проверяемый вариант использования — перевод NFSIISE на русский; проект не ограничен одним языком.

**Состояние:** исследование форматов и экспериментальный перевод. Готового графического редактора, установщика и полноценной поддержки шрифтов пока нет.

## Что уже проверено

- Текстовые ресурсы `text.*` содержат таблицу записей и строки; экспериментальный русский текст отображается в NFSIISE.
- Шрифты `.ffn` можно изменить для отображения кириллицы. Тестовые модификации проверены в игре на Linux, но ещё не готовы к распространению.
- В `translations/ru-experimental.json` сохранены изменения экспериментального перевода по индексам строк, а не исходный файл игры. Это рабочий материал, а не готовый устанавливаемый русификатор.

Подробности и ограничения: [docs/research.md](docs/research.md).

## Экспорт экспериментального перевода

`tools/export_translation.py` сравнивает два предоставленных пользователем файла `text.*` и сохраняет изменённые строки в JSON. Для проверенного русского эксперимента используется Windows-1251 со специальной заменой байта `98` на `я`. Это **не универсальная кодировка NFS** и не подходит без соответствующего модифицированного шрифта.

```sh
python3 tools/export_translation.py ORIGINAL_TEXT TRANSLATED_TEXT OUTPUT.json
```

Скрипт не изменяет исходные файлы и не перезаписывает существующий выходной файл. Импорт и сборка игрового файла пока не реализованы. Данные зависят от порядка записей и версии конкретного файла, поэтому их нельзя без проверки применять к другим версиям игры.

## Ресурсы и лицензия

Код проекта распространяется по [MIT](LICENSE). Игровые ресурсы EA и шрифты DejaVu в репозиторий не включены; для работы пользователь должен предоставить собственные файлы игры. Права на экспериментальный перевод и его распространение следует оценить отдельно от лицензии на код.
